What tau means, and the limits

tau is the share of its lending that a bank can lose before it fails: capital after the shock, divided by the loss rate and by what the bank lends. The three sliders are therefore one single knob. Two settings with the same tau give exactly the same cascades. A low tau means weak banks. Banks differ: each one has its own threshold around the mean. Real banks sit at high values (about 0.85 to 1.15 on rough averages), where one failure does little; the low values are a stressed case.

The rule is the sequential default algorithm (Furfine 2003) with a fixed loss given default. Only one channel of contagion is modelled (solvency). The page runs the same rule as the Python code of the repository, and a test checks that both give the same 1,800 cascades.
